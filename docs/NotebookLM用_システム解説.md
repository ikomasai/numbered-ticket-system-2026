# 整理券発券システム 完全解説ドキュメント

このドキュメントは「整理券発券システム」の全機能を詳細に解説するものです。
NotebookLMでの学習に最適化し、テキストベースで全ての画面・操作・仕様を網羅しています。

---

## システム概要

整理券発券システムは、大学祭における整理券の発券・呼び出し・状況確認を行うためのWebアプリケーションです。企画の担当者（係員）が主に使用し、お客さんは電子整理券の受け取り時にのみQRコードを読み取ります。

パソコンとスマートフォンの両方に対応しており、ブラウザからアクセスして使用します。複数の端末から同時に操作でき、呼び出し番号はリアルタイムで全端末に同期されます。

### 技術構成（参考情報）

- フロントエンド: React Native (Expo) のWeb版
- バックエンド: Supabase（データベース・認証・リアルタイム通信）
- 電子整理券: Supabase Edge Functions

---

## 企画の2つのタイプ

このシステムは2種類の企画タイプに対応しています。全ての機能はこの2タイプに基づいて動作が分かれます。

### 時間枠定員制

時間枠ごとに定員を設け、枠単位で整理券を発行するタイプです。

具体例: お化け屋敷の企画で、10:00〜10:30の回は定員20名、10:30〜11:00の回も定員20名、というように時間枠ごとに人数が決まっています。お客さんは指定された時間枠に来場します。

設定する項目は以下の通りです。
- 企画名（例: お化け屋敷）
- 企画場所（例: E館）
- 1枠あたりの定員（例: 20人）
- 1枠あたりの時間（分単位、例: 30分）
- 開催日（チェックボックスで選択）
- 各開催日の開始・終了時刻

時間枠は設定に基づいて自動生成されます。例えば開始10:00、終了19:00、枠時間30分の場合、10:00〜10:30、10:30〜11:00、...、18:30〜19:00 の18枠が自動で作られます。

### 順次案内制

時間枠を設けず、空きが出たら順番に案内するタイプです。

具体例: 模擬店の行列整理で、整理券番号の若い順に「次の方どうぞ」と案内していきます。お客さんは整理券をもらったら、自分の番号が呼ばれるまで待ちます。

設定する項目は以下の通りです。
- 企画名（例: 模擬カフェ）
- 企画場所（例: 近大）
- 1グループあたりの推定待ち時間（分単位、例: 10分）
- 開催日（チェックボックスで選択）

順次案内制には「発券グループ」という概念があります。1回の発券操作でまとめて発行された整理券が1つのグループです。1人で発券すればNo.1が1グループ、3人まとめて発券すればNo.2〜4が1グループです。呼び出しや待ち時間の計算は、このグループ単位で行います。

## 認証とアクセス制御

システムにアクセスするにはメールアドレスとパスワードによるログインが必要です。企画制作部のロール（権限）を持つユーザーのみがアクセスできます。

ログイン画面では以下の情報を入力します。
- メールアドレス
- パスワード

認証情報は事前に配布され、ログイン機能は限定配布のため、新規登録機能はありません。ログイン後は画面左下（パソコン）またはハンバーガーメニュー内（スマートフォン）にユーザー名が表示されます。

ログアウト時には確認ダイアログが表示され、確認後にログアウトが実行されます。

- 呼び出し（アイコン: 呼）

右側のメインエリアに各機能の画面が表示されます。

画面上部にヘッダーがあり、左側にハンバーガーメニューアイコン（☰）、中央に「整理券発券システム」のタイトルが表示されます。

画面下部にタブバーがあり、4つのタブが横に並びます。
- 企画管理
- 発券
- 呼び出し
- 状況確認

デフォルト設定とログアウトは、ハンバーガーメニューの中に配置されています。ハンバーガーメニューを開くとスライドメニューが左から表示され、ユーザー名、「デフォルト設定」ボタン、「ログアウト」ボタンが表示されます。

## 企画管理機能の詳細

### 企画一覧画面

企画管理タブを開くと、登録済みの全企画が一覧表示されます。企画は「時間枠定員制」と「順次案内制」の2カテゴリに分かれ、それぞれの件数が表示されます。

各企画はカード形式で表示され、以下の情報が含まれます。
- 企画名（太字）
- 企画タイプのバッジ（時間枠定員制は青、順次案内制はオレンジ）
- 開催場所
- 開催日一覧
- 各開催日の発券ステータスバッジ
- 「発券設定」ボタン（青色テキスト）
- 「削除」ボタン（赤色テキスト）

右上に「新規登録」ボタン（青いボタン）があります。

### 企画登録画面

新規登録ボタンを押すと、企画登録画面に遷移します。以下のフォーム項目があります。

1. 企画名（テキスト入力、プレースホルダー: 例：お化け屋敷）
2. 企画場所（テキスト入力、プレースホルダー: 例：1号館3階 301教室）
3. 企画タイプ（ラジオボタン）
   - 時間枠定員制: 「時間枠ごとに定員を設定」という補足テキスト付き
   - 順次案内制: 「空きが出次第、順番に案内」という補足テキスト付き
4. 時間枠定員制を選んだ場合:
   - 1枠あたりの定員（数値入力、プレースホルダー: 例：20）
   - 1枠あたりの時間（分）（数値入力、プレースホルダー: 例：30）
5. 順次案内制を選んだ場合:
   - 1グループあたりの推定待ち時間（分）（数値入力）
6. 開催日（チェックボックス群）
7. 各開催日の時刻設定

画面下部に「キャンセル」ボタン（白背景に青テキスト）と「登録」ボタン（青いボタン）があります。

### 発券ステータスの管理

企画カードの「発券設定」ボタンを押すと、各開催日のステータスを変更できます。

ステータスには5種類あります。
- 未発券（not_started）: まだ発券を開始していない状態。グレーのバッジで表示。
- 発券中（active）: 整理券を発行中の状態。緑のバッジで表示。手動で「発券中」に変更すると発券が可能になる。
- 発券停止中（paused）: 一時的に発券を停止した状態。オレンジのバッジで表示。トラブル対応等で使用。
- 満員（full）: 定員に達した状態。赤のバッジで表示。時間枠定員制で自動的に切り替わる。
- 発券終了（ended）: 発券を終了した状態。グレーのバッジで表示。手動変更または時間枠の開始時刻経過で自動変更。

自動ステータス変更のルール:
- 時間枠定員制で、ある枠の発券数が定員に達すると、その枠は自動的に「満員」になる。
- 時間枠定員制で、時間枠の開始時刻を過ぎると、その枠は自動的に「発券終了」になる。例えば現在11:20の場合、10:00〜11:00の枠は「発券終了」だが、11:00〜12:00の枠はまだ有効。

### 企画の編集

企画カードをタップまたはクリックすると編集画面に遷移します。登録画面と同じフォーム項目が表示され、既存の値が入力された状態になっています。変更後に「更新」ボタンで保存します。

### 企画の削除

「削除」ボタンを押すと確認ダイアログが表示されます。削除すると、その企画に関連する全データ（時間枠、整理券、呼び出し状態、発券ログ）もカスケードで削除されます。削除は取り消しできません。

## 発券機能の詳細

### 発券一覧画面

発券タブを開くと、発券対象の企画一覧が表示されます。企画名で検索できる検索ボックスがあります。企画は時間枠定員制と順次案内制のカテゴリに分かれて表示されます。各企画カードには企画名、場所、タイプバッジが表示され、右側に「>」マークがあり、タップすると発券詳細画面に遷移します。

### 時間枠定員制の発券詳細画面

画面上部に企画名がヘッダーとして表示され、左矢印で一覧に戻れます。

日付タブが横に並び（例: 11/2(月)、11/3(火)、11/4(水)）、選択した日付が青いボタンで表示されます。

画面は左右に分かれています。

左側（発券操作エリア）:
- 企画名と「時間枠定員制」バッジ
- 場所
- 選択中の日付とステータスバッジ
- 発行媒体の選択: 紙（デフォルト選択）/ 電子（ラジオボタン）
- 発券枚数: 「-」ボタン、数字、「+」ボタン
- 「発券する」ボタン（時間枠を選択するまではグレーアウト）

右側（時間枠選択エリア）:
- 「時間枠を選択」という見出し
- 時間枠が2列のグリッドで表示
- 各枠には時間帯（例: 10:00〜10:30）と発券数/定員（例: 12/20）が表示
- 発券数に応じて数字の色が変わる（少ない: 青、多い: オレンジ、満員: 赤）
- 満員の枠は黄色背景でグレーアウトされ選択不可
- 枠を選択するとハイライト表示

発券実行後:
- 紙媒体の場合: 整理番号、時間枠、企画名、日付が大きく表示される。係員はこの画面を見せて対応する紙の整理券を手渡す。
- 電子媒体の場合: QRコードが画面に表示される。お客さんがQRコードを読み取ると確認ページが開き、整理券情報がスマートフォンに保存される。

### 順次案内制の発券詳細画面

画面構成は時間枠定員制と類似していますが、右側の表示が異なります。

左側（発券操作エリア）:
- 企画名と「順次案内制」バッジ（オレンジ色）
- 場所
- 選択中の日付とステータスバッジ
- 発行媒体の選択: 紙 / 電子
- 発券枚数: 「-」「+」ボタン
- 「発券する」ボタン（常に青色で有効）

右側（発券・呼び出し状況エリア）:
- 「発券・呼び出し状況」という見出し
- 最後尾番号（大きな数字で表示、例: 37）
- 現在の呼び出し番号（大きな数字で表示、例: 17）
- 推定待ち時間（緑色の大きなテキスト、例: 約1時間40分）
- 待ちグループ数（例: (10グループ待ち)）

推定待ち時間の計算式: 未呼び出しグループ数 × 1グループあたりの推定待ち時間

### 整理番号の採番ルール

- 時間枠定員制: 企画・日付ごとに通し番号。日付が変わるとリセット。
- 順次案内制: 企画・日付ごとに1から順番。日付が変わるとリセット。
- 複数端末から同時発券しても番号の重複は発生しない（トランザクション処理による保護）。

## 呼び出し機能の詳細

### 呼び出し一覧画面

呼び出しタブを開くと、呼び出し対象の企画一覧が表示されます。発券一覧と同様のレイアウトで、検索ボックスと企画カードが表示されます。

### 時間枠定員制の呼び出し詳細画面

1. 日付タブを選択
2. 呼び出す時間枠を選択
3. 「呼び出し」ボタンを押す
4. 全画面表示で時間枠情報が表示される（例:「10:30の回」）

### 順次案内制の呼び出し詳細画面

画面は左右に分かれています。

左側:
- 企画名と「順次案内制」バッジ
- 場所
- 日付とステータス
- 「現在の呼び出し番号」が大きな数字で表示（例: 17）
- 「呼び出し」ボタン（グループを選択するまではグレーアウト）

右側（グループ選択エリア）:
- 「グループを選択して呼び出し」という見出し
- 発券グループのリスト
- 各グループは「No. X」または「No. X 〜 Y」形式で表示
- 呼び出し済みグループ: 緑色の背景で「呼び出し済み ✓ No. X」と表示。右側に「タップで訂正」テキスト。
- 未呼び出しグループ: 白背景で「No. X」と表示。タップで選択可能。

グループを選択して「呼び出し」ボタンを押すと:
- 全画面で「○番まで呼び出し中」と表示
- Supabase Realtimeにより、他の端末にもリアルタイムで呼び出し番号が反映される

呼び出し済みグループを選択した場合:
- 「呼び出し訂正中」と表示される
- 確定時に「本当に呼び出し番号を訂正しますか？」の確認ダイアログが表示される
- これにより、呼び出し間違いの訂正が可能

### リアルタイム同期

呼び出し番号の更新はSupabase Realtimeを使用して全端末に即時反映されます。これにより、複数の係員が異なる端末で呼び出し状況を同時に確認できます。

## 状況確認機能の詳細

### 状況確認一覧画面

状況確認タブを開くと、確認対象の企画一覧が表示されます。発券一覧や呼び出し一覧と同様のレイアウトです。

### 時間枠定員制の状況確認詳細画面

画面上部に企画名ヘッダー、日付タブがあります。

左側に企画情報（企画名、タイプバッジ、場所、日付、ステータス）が表示されます。

右側に「時間枠ごとの発券状況」が2列のグリッドで表示されます。各時間枠カードには以下が含まれます。
- 時間帯（例: 10:00〜10:30）
- ステータスバッジ（発券中、満員、発券終了 など）
- 発券数/定員（例: 12/20）。発券数は色付きで表示される。
- プログレスバー: 発券率に応じた色で表示される。
  - 緑: 発券率が低い（閾値「低」以下）
  - 黄色: 中程度（閾値「中」以下）
  - オレンジ: 高い（閾値「高」以下）
  - 赤: 非常に高い（閾値「非常に高」以上）
- 発券率パーセンテージ（例: 60%）

閾値はデフォルト設定画面で変更できます。初期値は低25%、中50%、高60%、非常に高80%です。

### 順次案内制の状況確認詳細画面

以下の情報が表示されます。
- 最後尾番号: 最後に発券された整理番号
- 現在の呼び出し番号: 現在呼び出し中の番号
- 推定待ち時間: 未呼び出しグループ数 × 1グループあたりの推定待ち時間
- 待ちグループ数: 現在待っているグループ数（例: 10グループ待ち）

## デフォルト設定機能の詳細

デフォルト設定は、システム全体の基本パラメータを管理する画面です。ここで変更した内容は全ユーザーに共有されます（Supabaseの numbered_ticket_settings テーブルに保存）。

アクセス方法:
- パソコン: サイドバーの「デフォルト設定」メニュー
- スマートフォン: ハンバーガーメニュー内の「デフォルト設定」ボタン

### 企画年

- 自動（現在の年）: システムが自動で現在の西暦を使用。ラジオボタンで選択。
- 手動入力: 任意の西暦を入力可能。ラジオボタンで選択後、入力欄に数値を入力。
- 「現在の年: 2026年」のように現在の設定が表示される。

### 企画日程範囲

企画登録時に選べる開催日の範囲を決定する設定です。

- 開始日: 月と日を個別に整数入力。例: 11月2日
- 終了日: 月と日を個別に整数入力。例: 11月4日
- 「この範囲内で企画日程を選択できます。」という説明テキスト付き。

企画年と日程範囲から、開催日一覧が自動生成されます。例えば2026年、11月2日〜11月4日の場合、2026-11-02、2026-11-03、2026-11-04の3日間が対象になります。

### 時間範囲共通設定

時間枠定員制で企画を新規登録する際の、デフォルト時間範囲です。

- 開始時間: 時と分を個別に整数入力。例: 10時00分
- 終了時間: 時と分を個別に整数入力。例: 19時00分
- 「新規登録から個別で設定できます。」という説明テキスト付き。

この設定はあくまで初期値であり、各企画の登録時に個別に調整できます。

### 配布率の閾値設定

状況確認画面のプログレスバーの色が変わる基準値です。パーセンテージで設定します。

- 閾値（低）: この値以下は緑色。初期値25%
- 閾値（中）: この値以下は黄色。初期値50%
- 閾値（高）: この値以下はオレンジ色。初期値60%
- 閾値（非常に高）: この値以上は赤色。初期値80%

設定変更後は「保存」ボタンで保存します。保存は即座に全ユーザーに反映されます。

## 運用上の重要ポイント

### 発券前の準備

1. デフォルト設定で企画年、日程範囲、時間範囲を正しく設定する
2. 企画管理画面で全企画を登録する
3. 発券開始前に、各企画のステータスを「発券中」に変更する

### 発券中の運用

- 複数端末で同時発券可能。整理番号の重複はシステムが自動防止。
- トラブル時は「発券停止中」に変更して一時停止。
- 定員に達すると自動で「満員」に変更される。
- 状況確認画面で発券状況をリアルタイムに監視できる。

### 呼び出し時の運用

- 順次案内制: グループ単位で呼び出し。複数端末でリアルタイム同期。
- 時間枠定員制: 時間枠単位で呼び出し。
- 呼び出し間違いは、呼び出し済みグループのタップで訂正可能。
- 発券終了後も呼び出し操作は継続可能。

### キャンセル対応

- 紙媒体: 整理券を回収する
- 電子媒体: 係員が整理番号をメモする

## よくある質問と回答

質問: 同時に複数の端末で操作できますか？
回答: はい、できます。複数の端末で同時にログインし、発券や呼び出しを行えます。呼び出し番号はリアルタイムで同期されます。発券時の整理番号の重複も、システムが自動で防止します。

質問: 定員に達したらどうなりますか？
回答: 時間枠定員制の場合、定員に達すると自動的に「満員」ステータスに変わり、その枠への発券ができなくなります。

質問: 時間枠の開始時刻を過ぎたらどうなりますか？
回答: 時間枠定員制の場合、時間枠の開始時刻を過ぎると自動的に「発券終了」になります。例えば11:20の時点で、10:00〜11:00の枠は「発券終了」ですが、11:00〜12:00の枠はまだ「発券中」のままです。

質問: 発券を一時的に止めたい場合は？
回答: 企画管理画面の「発券設定」ボタンから、ステータスを「発券停止中」に変更してください。再開する場合は「発券中」に戻します。

質問: 電子整理券のQRコードが読み取れない場合は？
回答: スマートフォンのカメラアプリまたはQRコードリーダーアプリで読み取ってください。それでも読み取れない場合は、紙媒体での発券に切り替えてください。

質問: 呼び出し番号を間違えた場合は？
回答: 順次案内制の場合、呼び出し画面で「呼び出し済み」のグループをタップすると訂正できます。確認ダイアログが表示されるので、訂正を確定してください。

質問: 発券終了後でも呼び出しはできますか？
回答: はい、できます。発券ステータスが「発券終了」や「発券停止中」でも、呼び出し操作は可能です。

質問: デフォルト設定を変更したら既存の企画にも反映されますか？
回答: いいえ、既存の企画には反映されません。デフォルト設定は新規企画登録時の初期値として使われます。既存の企画を変更したい場合は、個別に編集してください。

質問: 推定待ち時間はどうやって計算されていますか？
回答: 未呼び出しグループ数に、企画登録時に設定した「1グループあたりの推定待ち時間」を掛けて算出しています。例えば1グループあたり10分で10グループ待ちなら、約100分（1時間40分）と表示されます。

質問: 企画を削除したらどうなりますか？
回答: 企画に紐づく全データ（時間枠、整理券、呼び出し状態、発券ログ）が完全に削除されます。削除は取り消しできないため、本当に不要な場合のみ実行してください。

## 用語集

| 用語 | 説明 |
|------|------|
| 時間枠定員制 | 時間枠ごとに定員を設け、枠単位で整理券を発行する企画タイプ |
| 順次案内制 | 時間枠なし。空きが出たら順番に案内する企画タイプ |
| 発券グループ | 順次案内制で、1回の発券操作でまとめて発行された整理券の単位 |
| 発券ステータス | 企画の発券状態。未発券・発券中・発券停止中・満員・発券終了の5種類 |
| 整理番号 | 整理券に割り振られる通し番号。企画・日付ごとにリセットされる |
| 紙媒体 | 物理的な紙の整理券。番号を画面で確認し、対応する紙を手渡す |
| 電子媒体 | QRコードで受け取るデジタル整理券。お客さんのスマートフォンに保存される |
| QRトークン | 電子整理券を識別するための固有の文字列。QRコードに埋め込まれる |
| リアルタイム同期 | 呼び出し番号の変更が全端末に即座に反映される仕組み |
| 閾値 | 状況確認画面で、発券率に応じてプログレスバーの色が変わる基準値 |
| デフォルト設定 | システム全体の基本パラメータ。全ユーザーで共有される |
| ドロワー | パソコン表示時の左側サイドバーメニュー |
| タブバー | スマートフォン表示時の画面下部のメニュー |
| ハンバーガーメニュー | スマートフォン表示時の左上の三本線アイコンから開くメニュー |
